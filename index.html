LazyTrans 隱私權政策

最後更新：2026 年 8 月 18 日

LazyTrans 沒有自己的伺服器。 開發者無法看到、也不會收到你的任何資料。本擴充功能不含任何分析、追蹤或回報程式碼。

一、翻譯時會傳送什麼、傳送給誰

在下列三種情況下，頁面上需要翻譯的文字內容會傳送至 你自己選擇並自備金鑰的 AI 服務商：

  • 你按下翻譯按鈕
  • 你選取文字使用「劃詞翻譯」
  • 你造訪已加入「自動翻譯清單」的網站

傳送對象為下列其中一家，取決於你在設定中的選擇：

  • Google Gemini — generativelanguage.googleapis.com
  • Anthropic Claude — api.anthropic.com
  • Groq — api.groq.com
項目是否傳送
待翻譯的文字字串會
目標語言名稱會
網址（URL）不會
頁面標題不會
Cookie不會
瀏覽紀錄不會
任何可識別你身分的資訊不會

這些文字送達服務商之後如何被處理，適用該服務商自己的隱私權政策， 請自行參閱其條款。LazyTrans 無法控制、也不參與該階段的處理。

二、儲存在你電腦上的資料

以下資料只存在你瀏覽器的本機儲存空間（chrome.storage.local），不會離開你的裝置：

  • 你填入的 API Key
  • 偏好設定：翻譯引擎、模型、目標語言、顯示模式、快取保留天數
  • 自動翻譯的網站清單
  • 翻譯快取：已翻譯過的文字與其譯文，用於避免重複呼叫 API 而重複付費

翻譯快取預設保留 30 天，你可以在設定中調整天數或隨時清除。 移除本擴充功能時，上述資料會由瀏覽器一併刪除。

三、你的 API Key

金鑰只存在你的瀏覽器本機，僅用於直接呼叫你所選擇的服務商 API。 開發者不會、也無法取得你的金鑰。 金鑰不會傳送給開發者或任何第三方，只會隨著翻譯請求送往你指定的那一家服務商。

四、權限說明

權限用途
storage儲存上述設定與快取，全部留在本機
activeTab點擊工具列圖示時取得目前網站名稱，供「加入自動翻譯」使用
<all_urls>你可能在任何網站需要翻譯，因此無法事先限定網域。在你主動觸發翻譯之前，不會擷取或傳送任何內容

五、不做的事

  • 不蒐集個人識別資訊
  • 不建立使用者帳號或識別碼
  • 不販售或分享資料給任何第三方
  • 不含分析、追蹤、遙測或錯誤回報程式碼
  • 不從遠端載入任何程式碼

六、政策變更

本政策如有修改，會更新本頁最上方的「最後更新」日期。 若涉及資料處理方式的重大變更，會在擴充功能的更新說明中一併告知。

七、聯絡方式

如對本政策有任何疑問，請透過 GitHub Issues 與我們聯繫。
